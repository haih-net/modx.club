Основа: website-template, коммит `4c580b97425e2fa4b14e46f3ca7d65042e9471e9`.
Клон создан 13 октября 2026 года из `/shared/www/marketing/repos/website-template`
командой `git clone --no-hardlinks`, с полной независимой историей и без чужих
незакоммиченных изменений. Upstream: `git@github.com:haih-net/website-template.git`.
Собственный удалённый origin не создан. Репозиторий исключён из индекса marketing.

## Запуск

```sh
npm ci --cache .cache/npm
npm run types
npm run build
PORT=4318 npm start
```

Локальный адрес: http://localhost:4318/. Старый сайт продолжает работать на порту 3000.
Для разработки: `PORT=4318 npm run dev` (сначала остановить свой production preview).
Проверки выполнены на имеющемся Node.js 24.21.0. Основа объявляет Node.js 22.22.3;
повторная проверка на целевом runtime потребуется перед публикацией.

## Содержание и оформление

Рабочие файлы:

- `app/Custom/content/index.json` — соответствие URL, HTML-файла, языка, метаданных и оболочки.
- `app/Custom/content/pages/*.html` — полное редактируемое содержание каждой страницы.
- `app/Custom/components/SiteLayout` — общая React-оболочка, меню, языковой переключатель, SPA-переходы и фокус.
- `app/Custom/components/SiteLayout/styles.ts` — исходная тема, перенесённая в Linaria, включая оформление Markdown и формул.
- `app/Custom/pages/StaticPage` — отображение файлового содержания и JSON-LD.
- `app/routes/modx-*.tsx` — тонкие адаптеры маршрутов.
- `public/media` — локальные изображения и шрифты; старый Next-сервер для них не нужен.

Сохраняются 86 страниц/вариантов каталога: 74 адреса двух исходных sitemap,
дополнительный `modx-docker-minishop` на двух языках, четыре страницы авторов,
четыре варианта пагинации и две старые статьи по ID. В каталоге 35 концептов.
Обе существовавшие языковые версии оставлены. Непубличные функции платформы
(редактор, вход, регистрация, задачи и рабочая база знаний агента) не подключены.

Разметка материалов перенесена из отрендеренного публичного HTML, чтобы сохранить
сложное содержание и тему без повторного преобразования Markdown. React гидратирует
оболочку и управляет навигацией; внутри файлов остаются обычные семантические ссылки.
HTML доверенный, редактируется владельцем в репозитории и не принимается от посетителя.
На сборке создаются HTML и данные страниц. Пагинация также предрендерится по адресам
`/concepts/page/2`, `/concepts/page/3` и английским аналогам; исходные адреса
`?page=2/3` работают с тем же файловым содержанием через сервер основы.
База данных, Prisma, Next, n8n, WebSocket агента и ChatWidget для страниц не нужны.
Служебные HTTP, логи и статистика общей основы сохранены.

Кнопки «Связаться», «Обсудить перенос», «Запросить аудит» и «спросите у моего агента»
(включая английские варианты) сохранены в HTML-комментариях с пометкой
«Временно скрыто: кнопка ИИ-агента». ИИ-виджет не подключается. Кнопка
«Как это работает» теперь ведёт к существующему разделу `#how`.

Исправлены технические проблемы старой разметки: вложенные main, отсутствие
единственного h1 на отдельных страницах, невалидная сериализация объекта цвета
в переключателе языка, фокус клавиатуры. Тексты и существующие авторские сведения
сохранены. Цвета, размеры и адаптивное оформление перенесены из старой темы.

`/en` перенаправляется на `/en/` (301). Два старых английских адреса статей по ID,
которые исходник возвращал как 404, перенаправлены на соответствующие английские
публикации со slug. Параметры запроса при редиректе сохраняются. Неизвестные пути
и отсутствующие ресурсы возвращают 404. Canonical, hreflang, Open Graph и sitemap
используют основной домен `https://modx.club`.

## Снимки и повторный импорт

`migration/current-2026-10-13` — актуальный исходный снимок, сделанный после
обновления старого сайта владельцем. Здесь сохранены карты XML, исходный HTML,
дата, адреса, CSS и список ресурсов. `migration/source` — более ранний,
неактуальный снимок; он сохранён только для сверки и не используется приложением.

`scripts/capture-current.mjs <новый-каталог>` снимает новую копию в отдельный,
ещё не существующий каталог. Он не перезаписывает `app/Custom/content`.
`scripts/prepare-snapshot.mjs` использовался для первичного принятия снимка и
отказывается перезаписывать существующее рабочее содержание. Редакторские
изменения нужно переносить вручную после сравнения, а не повторным импортом.

## Проверки

```sh
npm run types
npm run test:migration
node tests/migration/browser.mjs
```

HTTP-проверка сама запускает собранную версию на порту 4319 и останавливает её.
Она проверяет все 86 страниц, исходные абзацы/списки/код, метаданные, изображения,
внутренние ссылки, якоря, sitemap, редиректы и 404.
Браузерная проверка использует запущенный preview на 4318, имеющийся Google Chrome,
ширины 1440 и 390, проверяет изображения, горизонтальный скролл, ошибки браузера,
SPA, историю, пагинацию, переключение языка и фокус. Снимки и результаты — в `.cache`.
Проверки прошли: типы, сборка, 86 HTTP/контент-проверок, 172 браузерных проверки
страниц на двух ширинах, SPA, история, пагинация, язык и фокус. Ошибок браузера
и горизонтального скролла не обнаружено. Скриншоты просмотрены, оформление
сопоставлено с актуальным старым сайтом.
Все временные файлы инструментов расположены внутри репозитория.

Публикация, DNS, сертификаты и настройки внешнего сервера не выполнялись.
