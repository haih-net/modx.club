Why We No Longer Develop New Websites on MODX

We do not offer the development of new websites on MODX.

Not because we don't know how. On the contrary: we know this platform, its core, xPDO, processors, templating, and component ecosystem far too well to recommend it for a new project today.

MODX can be maintained. It can be customized. An older website can be kept in production for years if it is generating revenue.

But a new project is a different story.

It does not yet have legacy code that needs to be preserved. It lacks accumulated SEO, data, integrations, and business processes that force you to tolerate the limitations of an older platform.

Creating a new website on MODX today means intentionally building technical debt that does not yet exist.

We see no point in doing that.

If you need a new project, it makes much more sense to build it from the ground up on an architecture that handles APIs, modern frontend development, automation, CI/CD, external services, and AI integrations properly.

For us, MODX is not a platform for a fresh start. It is legacy systems that we know how to carefully migrate existing businesses away from.
